// Java 21+ Project Loom: High-Throughput Concurrency
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    IntStream.range(0, 100_000).forEach(i -> {
        executor.submit(() -> {
            // Virtual thread parks on I/O without blocking OS carrier thread!
            Thread.sleep(Duration.ofMillis(100));
            return "Task " + i + " completed on " + Thread.currentThread();
        });
    });
} // Automatic structured join at close of scope!
Senior Architect Note: Notice how newVirtualThreadPerTaskExecutor() spawns an unbacked virtual thread per request. Unlike platform thread pools where tasks queue up waiting for an available OS thread, virtual threads execute immediately and unmount from their carrier thread whenever blocking I/O (sockets, JDBC, HTTP calls) occurs.
